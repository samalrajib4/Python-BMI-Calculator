BMI Calculator in Python

A simple BMI (Body Mass Index) Calculator built using Python in Jupyter Notebook. This project allows users to input their weight and height, calculates their BMI, and provides a categorization based on the result.
Features

    Input weight and height

    Calculate BMI based on the provided values

    Display BMI with corresponding weight category (Underweight, Normal weight, Overweight, Obesity)

    Built using Python in a Jupyter Notebook

Installation

To run the BMI Calculator on your local machine:

1. Clone the repository:
      git clone https://github.com/yourusername/BMI-Calculator.git
2. Install Jupyter Notebook if you don't have it:
     pip install notebook
3. Navigate to the project directory:
     cd BMI-Calculator
4. Start Jupyter Notebook:
    jupyter notebook
5. Open the BMI_Calculator.ipynb file in the Jupyter Notebook interface and run the cells to interact with the BMI calculator.

Usage

    Run the notebook.

    Input your weight (kg) and height (m) when prompted.

    The BMI value and corresponding weight category will be displayed.

Example:-
  Weight: 70 kg
  Height: 1.75 m
  BMI: 22.86
  Category: Normal weight

Technologies Used
